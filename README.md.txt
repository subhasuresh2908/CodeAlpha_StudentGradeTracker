# Student Grade Tracker

## About the Project
Student Grade Tracker is a Java-based console application developed as part of the CodeAlpha Java Programming Internship.

This application helps users manage student details and marks, calculate average marks, identify the highest and lowest marks, and assign grades.

## Features
- Add new student details.
- Prevent duplicate student IDs.
- View all student records in a formatted table.
- Calculate average marks of students.
- Find the highest marks.
- Find the lowest marks.
- Automatically calculate student grades.
- Validate marks between 0 and 100.

## Technologies Used
- Java
- NetBeans IDE
- ArrayList
- Object-Oriented Programming (OOP)

## Grade Calculation

| Marks | Grade |
|---|---|
| 90–100 | A |
| 80–89 | B |
| 70–79 | C |
| 60–69 | D |
| Below 60 | F |

## How to Run
1. Open the project in NetBeans IDE.
2. Open the `StudentGradeTracker.java` file.
3. Run the project.
4. Select an option from the console menu.
5. Enter student details and marks.

## Project Structure
- `Student.java` – Stores student details and calculates grades.
- `GradeManager.java` – Manages student records and performs calculations.
- `StudentGradeTracker.java` – Main class that runs the application.
